# Bitcoin Purchasing Power Dashboard v2

The v2 application is organized into small Google Apps Script modules for dashboard reconstruction, collection, source adapters, validation, data models, configuration, runtime utilities, tests, and frontend partials. The measurement contract is documented in `MEASUREMENT_SPEC.md`.

Run `testMeasurementContract()` after syncing the project. The result should report version `2.0.0` and `ok: true`.
